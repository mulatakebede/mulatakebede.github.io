// NLP · Low-Resource

Ge'ez Language POS Tagger

Built the first part-of-speech tagger for Ge'ez — one of Africa's oldest languages — achieving 94.32% accuracy using a novel hybrid TnT + rule-based + regex approach. Created the first annotated corpus: 15,154 words from 1,305 sentences.

TnT Tagger Hybrid NLP Published · AAU ETD
